# Third-party notices

## wordfreq-derived popup autocomplete datasets

The bundled popup autocomplete datasets under `public/data/autocomplete_datasets/` are generated offline from the [`wordfreq`](https://github.com/rspeer/wordfreq) project.

- These JSON files are generated artifacts, not hand-curated source lists.
- Regenerate them with `npm run build:autocomplete-datasets` after installing `wordfreq` in your local Python environment.
- Review the current `wordfreq` project license and attribution requirements before redistributing updated generated datasets.
