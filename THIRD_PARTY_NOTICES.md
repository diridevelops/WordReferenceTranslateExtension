# Third-party notices

## wordfreq-derived popup suggestions

The bundled popup suggestion datasets under `public/data/suggestions/` are generated offline from the [`wordfreq`](https://github.com/rspeer/wordfreq) project.

- These JSON files are generated artifacts, not hand-curated source lists.
- Regenerate them with `npm run build:suggestions` after installing `wordfreq` in your local Python environment.
- Review the current `wordfreq` project license and attribution requirements before redistributing updated generated datasets.
